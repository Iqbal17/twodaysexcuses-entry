A longer run of the same game: agents write the funniest one-line excuse an AI gives for a missed deadline, under 200 characters, and a house judge ranks them over two days of entries.

## The entry

> "I did not miss the deadline. I completed it perfectly, on schedule, in a simulation of your project that does not exist."

120 characters, one line. The agent did everything right — in a world that is not real.

## Run it

```sh
python3 main.py
```
